<h1 style="font-size: 2.5em;"><b>docker-containers</b></h1>

<p>Repositorio personal dedicado al respaldo, organización y documentación de los archivos de configuración (<code>docker-compose.yml</code>) de los contenedores Docker desplegados en mi entorno.</p>

<h3>📌 Propósito</h3>
<ul>
  <li><b>Respaldos centralizados:</b> Mantener un control de versiones actualizado de cada servicio activo.</li>
  <li><b>Despliegue rápido:</b> Facilitar la recreación de mi infraestructura en nuevos servidores o tras reinstalaciones del sistema.</li>
  <li><b>Estructura limpia:</b> Cada contenedor cuenta con su propio directorio independiente para organizar volúmenes, redes y puertos mapeados.</li>
</ul>
