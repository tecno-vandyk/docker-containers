Portainer con Docker Compose v2

¿Qué es Portainer?

Portainer es una interfaz web para la gestión de entornos Docker: contenedores, imágenes, volúmenes y redes. Se ejecuta como un contenedor en sí, 
aquí desde la imagen portainer/portainer-ce:2.40.0. Habla con el demonio a través del socket /var/run/docker.sock que el archivo de composición 
se monta en él. Su interfaz se sirve a través de HTTPS en el puerto 9443 del host.
